An account with no active plan can use only: `/api/account` (sign-in, email verification, claims), `/api/session` (sign-in session), `/api/whoami-user` (sign-in identity), `/api/profile` (account settings), `/api/settings` (account settings), `/api/billing` (Manage Plan, checkout, billing history), `/api/me` (entitlements (drives Choose a plan)), `/plans` (the public plan catalog), `/health` (health check), `/public` (website landing data), `/mcp` (admin-issued API keys (McpApiKeyGuard)), `/live/stream` (needs a stream ticket, issued only on a plan), `/live/tape/stream` (needs a stream ticket, issued only on a plan). Screens: auth, verify-email, settings, profile, manage-plan, checkout, billing, legal, version.
