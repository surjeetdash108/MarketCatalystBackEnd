TRACE

What happens when you open the dashboard

One page load exercises five of the seven patterns at once — here is the order they fire.

1
Load — Firebase Hosting serves the static bundle to the browser. (conn 1)
2
Authenticate — onAuthStateChanged restores the session; the ID token identifies the user for owner-scoped Firestore rules. (conn 2 · pattern B gate)
3
Subscribe — each widget's useCollection opens a Firestore listener; indices, movers, sectors, F&G, earnings paint from pushed snapshots. (pattern A)
4
Go live — the shell opens one SSE stream for the ticker tape and shares the frame to the Market Pulse boxes + index drawer, so all three agree. (pattern D)
5
Price poll — watchlist / portfolio / stock quotes poll /live/snapshot every 15s; the server collapses them to one Polygon call. (pattern C)
6
Meanwhile, off-screen — Cloud Scheduler keeps firing the worker on cron, refreshing the very collections step 3 is subscribed to. (pattern F)
